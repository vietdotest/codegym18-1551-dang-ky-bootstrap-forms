# Đăng ký với Bootstrap Forms

Đủ họ tên, email, mật khẩu, xác nhận mật khẩu, giới tính radio, sở thích checkbox, quốc gia select và submit btn-primary. Native validation và kiểm tra hai mật khẩu; dữ liệu không gửi đi.

## Chạy
Mở index.html. Cần Internet để tải Bootstrap 5.3.0 CSS và bundle từ jsDelivr, đúng phiên bản trong đề thực hành.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1551

## Kiểm tra
375, 768, 1440 px không tràn ngang, ảnh tải đủ. Mật khẩu khác nhau bị báo chưa khớp; khớp và email hợp lệ thì Submit hiển thị trạng thái biểu mẫu hợp lệ. Chọn quốc gia hoạt động.
